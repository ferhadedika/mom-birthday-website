# Photos go here

Drop your photos into this folder using the exact filenames below. Each one
will replace its matching placeholder on the site automatically. No code
changes needed, just add the file and refresh.

Any common image format works (.jpg, .jpeg, .png, .webp) as long as the
filename matches exactly, including the extension.

| Filename              | Where it appears                     |
|-----------------------|---------------------------------------|
| hero.jpg              | Large photo at the top of the site    |
| memory-couple.jpg     | Favorite Memories, "Family"           |
| memory-cafe.jpg       | Favorite Memories, "Sweet Treats"     |
| memory-flowers.jpg    | Favorite Memories, "Flowers For You"  |
| memory-beach.jpg      | Favorite Memories, "By The Sea"       |
| memory-mask.jpg       | Favorite Memories, "Just Us"          |

A tall portrait photo works best for `hero.jpg` and the memory photos.

If you'd rather use different filenames, update the matching `src` value in
`lib/content.ts` instead.
